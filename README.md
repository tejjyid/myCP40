This is a simple interface to query a database of the CP40 data as documented online by the AALT projext at the University of Houston. 
The data covers the period from 1349 to 1648. There are roughly 650,000 cases indexed.

It's specifically focused on genealogical research and provides stardard potted report summaries based on user-input for surname and period. Thus,
it is possible to search for "Webb" (lists of names are supported) from, say, 1350 to, say, 1430, either as defendant, or plaintiff, or both. 
The app will provide summaries by county & decade & profession. I will add summary by writ when the data is finally properly clean.
